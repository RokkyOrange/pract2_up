# Практическая работа 2. Списки, поиск, фильтрация и пагинация

Клиент цветочного магазина на Flutter Web: каталог букетов и флористов.
Данные хранятся в памяти, состояние управляется через `provider`,
маршрутизация выполнена на `go_router`.

## Слои

| Каталог | Назначение |
|---|---|
| `lib/models` | модели `Bouquet`, `Florist`, `PageResult<T>`, параметры запроса |
| `lib/repositories` | интерфейсы репозиториев и реализации в памяти, начальный набор данных |
| `lib/state` | `ChangeNotifier` для списков и переключатель имитации ошибки сервера |
| `lib/screens` | экраны списков и карточек |
| `lib/widgets` | переиспользуемые виджеты: состояния загрузки, поиск, пагинация |

## Маршруты

| Адрес | Экран |
|---|---|
| `/` | Главная |
| `/bouquets` | Список букетов |
| `/bouquets/:id` | Карточка букета |
| `/florists` | Список флористов |
| `/florists/:id` | Карточка флориста |
| любой другой | Страница 404 |

## Запуск

```bash
flutter pub get
flutter build web
npx serve -s build/web -l 5555
```

Или в режиме отладки: `flutter run -d edge --web-port=5555`.

## Проверка

```bash
flutter analyze
flutter test
```
